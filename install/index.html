Cài xưởng viết

Chạy trên máy bạn, Windows hoặc macOS. Không máy chủ, không tài khoản, không token. Cách dễ nhất: dán một prompt cho ứng dụng AI bạn đang dùng, agent tự làm các bước và hỏi bạn trước khi cài phần mềm hay đặt biến môi trường.

1. Dán prompt cho agent

Tiếng Việt

Cài agent-writing-studio cho tôi. Đọc và làm theo đúng
https://github.com/ducnguyen221/agent-writing-studio/blob/main/INSTALL.md
Trước khi cài phần mềm, đặt biến môi trường hay clone repo, hãy nói rõ bạn
sẽ làm gì và chờ tôi đồng ý. Không mở file bí mật. Cài xong, chạy
`python studio.py doctor`, chép nguyên kết quả, rồi hướng dẫn tôi làm bài mẫu
trong START-HERE.md.

English

Install agent-writing-studio for me. Read and follow exactly
https://github.com/ducnguyen221/agent-writing-studio/blob/main/INSTALL.md
Before installing software, setting environment variables or cloning, tell
me what you will do and wait for my approval. Do not open secret files.
When done, run `python studio.py doctor`, paste its output verbatim, then walk
me through the sample in START-HERE.md.

Plugin mang nguyên cây repo: 9 skill, 7 lệnh /agent-writing-studio:* và dữ liệu dùng chung. Mở phiên mới rồi gõ /agent-writing-studio:list.

Codex, Antigravity, hoặc bản clone

git clone https://github.com/ducnguyen221/agent-writing-studio
cd agent-writing-studio
python studio.py install --host codex     # hoặc antigravity; macOS có thể là python3
python studio.py doctor

Mở chính thư mục repo trong ứng dụng AI. Agent đọc AGENTS.md trước rồi tự tìm đúng skill. studio.py cần Python 3.10 trở lên; nó chỉ dựng thư mục làm việc và in lệnh, không sửa cấu hình của ứng dụng AI.

3. Dữ liệu của bạn nằm đâu

Mặc định: .work/<tên-ca>/ trong thư mục bạn mở — Git bỏ qua toàn bộ, không phải cấu hình gì. Muốn dữ liệu sống lâu hơn bản clone (nhiều máy, nhiều checkout) thì đặt một station riêng — tuỳ chọn:

setx WRITING_STUDIO_DATA "$HOME\.writing"                        # Windows, mở terminal mới sau đó
echo 'export WRITING_STUDIO_DATA="$HOME/.writing"' >> ~/.zshrc   # macOS
python studio.py install                                          # dựng work/ out/ corpus/

Bản giao .docx ghi vào thư mục bạn chỉ định, không nằm lẫn trong workspace hay station.

4. Kiểm, cập nhật, gỡ

  • python studio.py doctor — mỗi dòng PASS / WARN / FAIL / NOT_CHECKED. Không có FAIL là dùng được; WARN ở thư viện là tuỳ chọn.
  • Cập nhật plugin: claude plugin update agent-writing-studio@agent-writing-studio. Bản clone: python studio.py update --yes (chỉ git pull --ff-only, từ chối khi có sửa dở).
  • Gỡ: python studio.py uninstall in lệnh gỡ; không xoá dữ liệu của bạn.
